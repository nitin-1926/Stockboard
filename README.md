# Stockboard

Personal, read-only portfolio dashboard for Indian (Zerodha Kite) and US (INDmoney) holdings. Built with Next.js and Neon Postgres, hosted on Vercel.

## Stack

- Next.js 16 (App Router, Cache Components), React 19, TypeScript
- Tailwind CSS v4 + shadcn/ui, next-themes, Geist fonts
- Neon Postgres + Drizzle ORM
- Better Auth (Google sign-in)
- Vitest (unit), Playwright (smoke)
- GitHub Actions for CI and scheduled jobs
